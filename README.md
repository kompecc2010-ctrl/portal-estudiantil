# 📚 Portal de Recursos Estudiantiles - Unidad Educativa Jambelí

¡Bienvenidos a nuestro portal académico en línea! Este sitio web ha sido diseñado y maquetado desde cero con fines educativos y estudiantiles, buscando centralizar información clave para nuestra comunidad escolar.

## 🚀 Características del Proyecto
* 📰 **Carrusel de Noticias:** Un módulo dinámico e interactivo automatizado con JavaScript que desplaza las novedades escolares cada 3 segundos.
* 📸 **Galería Institucional:** Espacio fotográfico interactivo que resalta los emblemas de nuestra institución y la Marina, con efectos visuales modernos de elevación y zoom suave.
* 📕 **recursos PDF:** Zona de descargas optimizada para abrir guías de estudio y cronogramas directamente en el navegador o guardarlos con un clic.
* 📩 **Formulario de Contacto:** Página independiente integrada con servidores en la nube para recibir consultas estudiantiles en formato de texto plano directamente en Gmail.

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructuración semántica y accesibilidad web.
* **CSS3:** Diseño limpio, maquetación adaptativa (Flexbox) y transiciones animadas.
* **JavaScript:** Lógica de temporización para el desplazamiento automático multimedia.
* **Vercel / Netlify:** Alojamiento seguro y despliegue global continuo.
